# 🎨 Eventric — UI/UX Design

**Eventric** is a modern mobile application UI/UX design created as part of an **ISD (Integrated Software Development) Project**.

The main goal of Eventric is to provide users with a simple and convenient platform for discovering events, viewing event details, selecting locations, registering for events, making payments, receiving digital tickets, and sharing events with friends.

The UI/UX design focuses on **simple navigation, clean layouts, clear information, and an easy-to-use user experience**. The complete interactive prototype was designed using **Figma**.

# ✨ Main Features

## 🏠 1. Home Screen

The Home Screen provides users with a quick overview of available and upcoming events.

Users can:

* Search for events
* Browse event categories
* View upcoming events
* Explore featured events
* View event images
* See event names and prices
* Quickly open event details

The design keeps the most important event information visible so users can easily explore available events.

---

## 🔎 2. Event Discovery

The Event Discovery section allows users to explore different events through an organized interface.

Users can:

* Browse available events
* Explore different event categories
* View event cards
* Check event prices
* Check event dates
* Check event locations
* Open complete event information

This section helps users find events based on their interests and available information.

---

## 📋 3. Event Details

The Event Details screen provides complete information about a selected event.

It includes:

* Event image
* Event title
* Event category
* Event date
* Event time
* Event location
* Event price
* Event description
* Join/participate option

Users can review the event information before deciding to participate.

---

## 📍 4. Location Selection

Eventric includes a location selection interface that helps users select and confirm an event location.

Users can:

* Search for a location
* View the location on a map
* Select a location
* Confirm the selected location
* Check the event location before participation

This makes location-related information easier to understand before joining an event.

---

## 👤 5. Profile

The Profile section provides users with account-related options and application settings.

Users can access:

* Manage Profile
* Notifications
* Change Password
* Terms & Conditions
* Support
* Manage Events
* Logout

The profile section keeps personal account and application settings organized in one place.

---

## 🔔 6. Notifications

The Notification section allows users to view important updates related to their events and activities.

Notifications may include:

* Event notifications
* Event reminders
* Payment updates
* Registration updates
* Ticket-related notifications
* General application notifications

This helps users stay informed about important event activities.

---

## 🏟️ 7. Manage Events

Eventric also includes an event management interface.

Event information that can be managed includes:

* Event name
* Event date
* Event time
* Event location
* Event category
* Event price
* Event description

This section is designed to help event organizers manage their event information from the application.

---

## 💳 8. Payment

Eventric includes a complete payment UI flow for event participation.

The design provides different payment options, including:

* UPI / Digital Payment
* Debit Card
* Credit Card
* Wallet

The payment interface is designed to keep the process simple and easy to follow.

---

## 💳 9. Add New Card

Users can add a new payment card through the payment interface.

The card form includes:

* Cardholder Name
* Card Number
* Expiry Date
* CVV

This allows users to provide their card information when using card-based payment options.

---

## ✅ 10. Payment Success

After a successful payment, users receive a payment confirmation screen.

The screen provides:

* Payment successful status
* Confirmation message
* Transaction/Order information
* Access to the digital ticket

This gives users confirmation that their event participation/payment process has been completed.

---

## 🎫 11. Digital Ticket

After successful registration or payment, users can access their digital event ticket.

The ticket contains important event information such as:

* Event name
* Event date
* Event time
* Event location
* Ticket information
* QR code
* Verification information

The digital ticket provides users with a convenient way to access their event entry information.

---

## 🔳 12. QR Code Verification

The digital ticket contains a QR code that can be used for ticket verification.

The intended ticket verification flow is:

**Payment → Ticket Generated → QR Code → Ticket Verification → Event Entry**

The QR-based system is designed to make event entry faster and easier by providing a digital method of checking tickets.

---

## 📤 13. Event Invitation

Users can invite friends or other people to participate in an event.

The invitation interface includes:

* Recipient information
* Recipient phone number
* Recipient name
* Invitation message
* Date
* Time
* Send Invitation option

This feature allows users to share event invitations directly with others.

---

## 👥 14. Contact & Social Sharing

Eventric also provides options for sharing event information with friends and contacts.

The UI includes sharing options such as:

* Contacts
* Messaging
* WhatsApp
* Gmail
* Instagram
* Other supported sharing options

This makes it easier for users to share interesting events with their friends and social connections.

# 🎯 Project Objectives

The main objectives of the Eventric project are:

* To design a modern and user-friendly event application.
* To make event discovery simple and convenient.
* To provide users with complete event information.
* To create an easy registration and payment flow.
* To provide digital tickets with QR-based verification.
* To allow users to share events and invite friends.
* To provide event management options for organizers.
* To create a clear and consistent mobile UI/UX experience.

---

# 🎨 Design Approach

The Eventric UI/UX design focuses on:

* **Simple Navigation** — Users can move between important sections easily.
* **Clean Interface** — Information is presented in an organized way.
* **User-Friendly Flow** — The event journey is divided into clear steps.
* **Consistent Design** — Similar elements follow a consistent visual structure.
* **Easy Information Access** — Important event information is easy to find.
* **Mobile-Focused Experience** — The interface is designed around a mobile application experience.

---

The prototype was created using:

# 📱 Application Flow

The main Eventric application flow can be summarized as:

**Home → Discover Event → Event Details → Location → Registration → Payment → Payment Success → Digital Ticket → QR Verification → Event Entry**

Additional flows include:

**Profile → Manage Account → Notifications → Settings**

and

**Manage Events → Create/Update Event Information → Event Management**

Users can also follow:

**Event → Invite Friends → Contact/Social Sharing**
